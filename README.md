# Netflix-SQL-Data-Analysis
Netflix SQL Data Analysis Project using Python, SQLite, Pandas, and Matplotlib. Analyzed 8,800+ Netflix titles to uncover content trends, ratings distribution, and business insights through SQL queries and visualizations.
# Netflix SQL Data Analysis

## Tools Used
- Python
- Pandas
- SQLite
- Matplotlib

## Project Overview
Analyzed 8,800+ Netflix titles using SQL queries and data visualization techniques.

## Key Insights
- Movies outnumber TV Shows.
- TV-MA is the most common rating.
- Netflix content increased significantly after 2015.
- Content is dominated by a few countries.

- SQL Queries
- Data Cleaning
